# 🏦 Bank Account Management System (Python)

A **menu-driven Bank / ATM Management System** built using **Python**, designed to practice core programming concepts like dictionaries, functions, loops, and conditional logic.

This project simulates basic banking operations such as account creation, login, deposit, withdrawal, and balance checking through a command-line interface.

---

## 🚀 Features

- Create a new bank account  
- Login using account number and PIN  
- Deposit money  
- Withdraw money with balance validation  
- Check account balance  
- Logout and return to main menu  
- Menu-driven user interaction  

---

## 🛠️ Technologies Used

- Python 3  
- Dictionaries  
- Functions  
- Loops (`while`)  
- Conditional statements  
- `match-case` (Python 3.10+)
